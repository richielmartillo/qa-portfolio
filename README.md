# Portfólio de Engenharia de Qualidade

Este repositório reúne meus projetos práticos em Engenharia de Qualidade de Software, organizados para apresentar minha evolução no aprendizado de testes, automação, DevOps e qualidade de forma clara e objetiva.

Aqui estão concentrados trabalhos que envolvem automação web, testes de API, testes de unidade, performance e integração contínua, sempre baseados em cenários próximos à realidade de aplicações de mercado.

## Objetivo do portfólio

## Objetivo do portfólio

- Demonstrar minha experiência prática em qualidade de software
- Apresentar projetos desenvolvidos ao longo dos meus estudos
- Mostrar a aplicação de boas práticas de testes, automação e organização
- Evidenciar minha capacidade de analisar contextos, definir estratégias e tomar decisões técnicas

Mais do que listar ferramentas, este portfólio busca mostrar como eu penso em qualidade.

## Projetos         

Abaixo estão alguns dos principais projetos que fazem parte deste portfólio.

Cada projeto possui sue próprio repositório e um README com a explicação do contexto, objetivo, estratégia de testes e testes e instruções de execução.

### Automação Web

Projeto focado em testes end to end de uma aplicação web, chamada hub-de-leitura-testes-ui-cypress,
 validando fluxos críticos e comportamentos esperados do sistema.

 **Tecnologías utilizadas:**
 - Cypress
 - Java Script

 Repositório:
 https://github.com/richielmartillo/hub-de-leitura-testes-ui-cypress

### Automação de API

 Projeto voltado para testes de API, cobrindo validações de regras de negócio, cenários positivos e negativos.

 **Tecnologias utilizadas:**

 - Cypress
 - Testes de API REST

 Repositório:
 https://github.com/richielmartillo/hub-de-leitura-api-cypress

### Testes de Unidade

 Projeto com exemplos de testes de unidade aplicados a funções e regras isoladas, com foco em confiabilidade e manutenção do código.

 **Tecnologias utilizadas:**
 - JavaScript
 - Framework de testes de unidade

 Repositório:
 https://github.com/richielmartillo/exercicio-js

 ## Desafios práticos

 Além dos projetos completos, este portfólio também inclui desafíos práticos voltados para o exercício de habilidades específicas.

 Os desafíos tem como foco:

 - raciocínio de testes
 - organização
 - tomada de decisão

## Boas práticas adotadas

Ao longo do projeto, busquei aplicar prática como:

- organização clara de pastas e arquivos
- uso adequado de `.gitignore`
- READMEs explicando contexto e objetivo
- código simples, legível e sustentável
- foco em manutenção e clareza

## Considerações finais

Este portfólio representa minha evolução prática na área de Qualidade de Software. Cada projeto foi desenvolvido com o objetivo de aplicar conceitos de testes manuais, automação, testes de API, integração contínua e boas práticas de desenvolvimento.

Durante essa jornada, enfrentei desafios relacionados à configuração de ambientes, estruturação de projetos, criação de cenários de teste e análise de falhas. Esses desafios contribuíram diretamente para o aprimoramento do meu raciocínio crítico, da organização e da capacidade de identificar problemas.

Continuarei atualizando este portfólio com novos projetos, melhorias e tecnologias, acompanhando minha evolução profissional como QA.
